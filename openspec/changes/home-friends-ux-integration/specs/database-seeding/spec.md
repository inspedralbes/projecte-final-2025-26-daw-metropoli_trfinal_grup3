## ADDED Requirements

### Requirement: Social Data Seeding
The system SHALL provide a mechanism to populate the database with a diverse set of mock users and friendship relationships to facilitate testing and demonstration of social features.

#### Scenario: Seed social data
- **WHEN** the seeding script is executed
- **THEN** the system SHALL insert at least 5 mock users with complete profile data (names, bios, avatars) and establish multiple friendship links between them
