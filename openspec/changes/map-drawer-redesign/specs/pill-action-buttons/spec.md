## ADDED Requirements

### Requirement: Floating Pill Actions
The map SHALL feature two horizontally centered pill-shaped buttons positioned immediately above the drawer's top handle.

#### Scenario: Centering the map
- **WHEN** the user clicks the "Centrar" pill button
- **THEN** the map SHALL fly to the user's current location

#### Scenario: Creating a new route
- **WHEN** the user clicks the "+" pill button
- **THEN** the route creation interface SHALL be initiated
