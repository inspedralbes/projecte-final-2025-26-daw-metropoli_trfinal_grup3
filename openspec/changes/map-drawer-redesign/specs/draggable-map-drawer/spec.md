## ADDED Requirements

### Requirement: Draggable Bottom Sheet
The map interface SHALL include a bottom sheet that can be dragged vertically to adjust its visible height.

#### Scenario: Dragging the drawer up
- **WHEN** the user drags the drawer handle upwards from the bottom of the screen
- **THEN** the drawer SHALL expand to show more content, following the user's finger movement

#### Scenario: Dragging the drawer down
- **WHEN** the user drags the drawer handle downwards
- **THEN** the drawer SHALL collapse to its initial "peek" state
